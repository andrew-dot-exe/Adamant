# Глоссарий
- Конспект лекций - общее название файла, в котором содержатся все конспекты по темам.
- Конспект по теме - отдельная лекция за определенную дату, которая представлена в виде текста. 

# Что нужно от конспекта лекций
Конспект лекций должен отображаться как непрерывно, так и дискретно, отдельными темами и прочее
Должны быть реализованы:
- Конспект за дату
- Конспект по теме
- Справочная информация (заметки на полях)
    - система сносок тоже не мешала бы, которая работала по тегу и вообще уже для пет-проекта как-то очень жирно
- Разделение конспектов по темам
# Структура файла
~~~
adamant-sample-note.nte
├── info.toml
├── lesson-date1.md
├── lesson-date2.md
├── lesson-date3.md
└── src
    ├── attach1.jpg
    ├── attach2.jpg
    ├── attach3.jpg
    └── attach4.jpg
~~~
NTE-файл это обычный zip-архив с файлами, которые представляют ту или иную дисциплину. В интерфейсе он должен отображаться как и список отдельных тем лекций, так и в непрерывном виде, когда все лекции идут один за другим по их логическому порядку. Всю информацию хранит в себе info.toml, все ресурсы (пока только картинки) хранятся в папке ```src/ ```
## Что в TOML
TOML-файл содержит в себе информацию о том, кто начал конспект лекций, дата начала, дата последнего изменения текстов лекций (может свой гит запилить еще?)
### Дополнительные теги в файлах конспекта тем
надо продумать, будет ли сервисное (да) поле в начале файла с конспектом темы для того, чтобы были какие-либо данные (авторство, чтобы можно было делиться не целым файлом, а только отдельной лекцией). 
Если делиться файлом с конспектом темы, то нужно делать файл как архив, который будет тоже иметь сервисное поле и src-папку.

# Что можно сделать с конспектом лекций
Конспект лекций можно:
- Просматривать по темам или непрерывно
- Сохранить как PDF-документ, тему или целиком
- Редактировать содержимое лекций
- (опционально) Защищать файл с помощью пароля
